# Goose School 🪿

Chrome extension that captures homework, schedule, and marks from Моя Школа while you browse.

## How to install

1. Open Chrome → `chrome://extensions`
2. Turn on **Developer mode** (top right)
3. Click **Load unpacked** → select the `extension` folder
4. Done — the goose icon appears in your toolbar

## How to use

1. Go to myschool.edu.ru and log in normally
2. Browse your diary / homework / marks
3. Click the goose icon — your data is there
